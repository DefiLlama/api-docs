DefiLlama API documentation

Explore free and Pro API endpoints for DeFi data.

Have an API key? Send every request to https://pro-api.llama.fi/… with the x-api-key: YOUR_API_KEY header, including prices, TVL, stablecoins and yields. The free hosts (api.llama.fi, coins.llama.fi, stablecoins.llama.fi, yields.llama.fi) never read a key and are rate limited.
